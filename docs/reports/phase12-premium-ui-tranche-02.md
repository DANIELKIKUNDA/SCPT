# Phase 12 — Premium UI/UX — Tranche 02

## Périmètre
Modernisation du workspace principal sans modification du domaine métier ni des contrats IPC.

## Changements
- hiérarchie visuelle du studio renforcée ;
- topbar projet plus compacte et informative ;
- panneaux scènes / preview / propriétés mieux séparés ;
- scène sélectionnée plus lisible ;
- canevas renforcé comme point focal ;
- barre d'outils basse transformée en navigation de production avec icônes ;
- cohérence des surfaces, bordures, rayons, focus et états actifs ;
- harmonisation Narration, Sous-titres, Médias et Formats ;
- responsive conservé ;
- reduced-motion respecté.

## Doctrine respectée
Le projet audiovisuel reste le centre du workspace. La refonte ne change ni les statuts, ni les agrégats, ni les règles de rendu. Elle cherche à faire percevoir SCPT comme un studio de production, avec la prévisualisation comme point focal et les outils spécialisés comme stations de travail.

## Validation à exécuter sur environnement équipé
`pnpm typecheck`, `pnpm test`, `pnpm build`, puis recette Electron Windows.
